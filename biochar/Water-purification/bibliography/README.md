# Water and filtration bibliography

Cite-first bibliography for biochar and activated carbon in water treatment and filtration.

This set is separate from soil and carbon-dioxide-removal science. The papers audit describes the broader top-20 list as mostly soil and climate work. That list can support carbon-dioxide-removal notes. It is the wrong default for filtration claims. Use this folder for water and filtration citations.

## Tiers

The shortlist CSV labels each paper. The audit defines the tiers as follows.

| Tier | What it is for |
| --- | --- |
| A | Default citations for general claims: peer-reviewed reviews, meta-analyses, and head-to-head comparisons. |
| B | Contaminant-class specialists: contaminant-specific primary studies and niche reviews. |
| C | Foundational carbon surface chemistry. Use for mechanisms, not for treatment-performance claims. The shortlist includes two tier C papers. |
| vendor | A lower tier. Product and marketing material, such as the Norit pack named in the audit. Use only for product context, and always pair it with tier A or B. Vendor material is not in the shortlist CSV. |

The audit also uses `standard` for EPA, NSF, AWWA, and IBI/EBC documents, and `do-not-cite-alone` for conference abstracts, preprints without peer review, and gated marketing pages. Those labels are not columns in the shortlist CSV. `report-references.md` uses `standard` only where the audit explicitly groups that report source with the standards, and it marks weaker items in prose instead of inventing a letter tier.
