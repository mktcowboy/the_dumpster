Scout notes — stats hunt, caveats, near-misses

The stats hunt — result: no public ranking source exists

  1. OSF API v2 (api.osf.io/v2/preprints/…): preprint and file records carry no download or view fields — verified directly in the JSON attributes.
  2. /v2/preprints/{id}/metrics/ and /analytics/: 404.
  3. /v2/metrics/ (repo code exists in CenterForOpenScience/osf.io, api/metrics/): 404 on production — code isn't deployed publicly.
  4. Detail-page HTML (osf.io/preprints/psyarxiv/{id}/): 4KB JS shell, no embedded counters. OSF's own help docs (https://help.osf.io/article/408-preprint-analytics) confirm each preprint has view/download counters, but they render only in the browser app and are not exposed by any public endpoint — corroborated by a peer-review discussion noting "download statistics are not available through the API".
  5. Altmetric API: now requires an API key (as of Nov 10, 2025) — blocked without one.
  6. PsyArXiv discover page (https://psyarxiv.com/discover): sort options are Relevance-only; no trending/most-downloaded view.
  7. OpenAlex / Crossref: fresh DOIs aren't indexed yet (404s), so cited-by counts are nonexistent at this age.

Bottom line: no verifiable download/view/attention ranking for month-fresh PsyArXiv preprints. Anyone claiming a download-ranked top 20 for this window would be making it up.

The stats hunt (what exists, what doesn't)

Real stats do exist, but only per-paper. Each OSF preprint page publicly displays "Views: X | Downloads: Y" counters (confirmed via OSF's own docs: https://help.osf.io/article/408-preprint-analytics — counters exclude views/downloads by the paper's own contributors). There is no public ranking or trending page for SocArXiv, and no metrics API: api.osf.io/v2/metrics/... returns 404, v2 preprint records don't carry counters, and the Altmetric API denied access (403) for these DOIs. The SocArXiv blog (socopen.org) only publishes aggregate submission counts, never per-paper leaderboards.

What was done: pulled all 100 SocArXiv preprints created Sep 18–Oct 18, 2026 via the OSF API, then opened each preprint's OSF page and read its counters (stats as of Oct 18, 2026, ~4:30–5pm CT). A 429 rate limit stopped the sweep partway — 65 of 100 papers measured, 35 could not be (mix of pages with no extractable counters and unfetched ones; no retries per hard-stop rule). So this is a top-20 by observed downloads among the 65 measured papers — not a complete ranking, and the true top-20 could differ. Methodology: sorted by downloads descending, ties broken by views descending. Zero editorial curation beyond that. Authors verified per-paper via the OSF citation API (api.osf.io/v2/preprints/{id}/citation/); all 20 URLs are live pages that were successfully fetched.

Biases to know: earlier-in-window papers had more days to accumulate downloads; papers posted Oct 15–16 are systematically disadvantaged. Download counts are small (max 25) because most papers are days old.

Ordering is by downloads where visible on the page, otherwise by attention/impact. Result is 5 papers, not 20: 15 candidates dropped because no SSRN page could be found or verified (fresh pages often aren't search-indexed yet; one confirmed-SSRN paper excluded for being posted Sep 2025, outside window). Statistics hunt — what was actually found

BUT: article pages return HTTP 403 to programmatic fetching (bot protection), and there is no sortable, date-filterable, or API-exposed ranking of these metrics anywhere.
  2. The ChemRxiv dashboard (https://chemrxiv.org/engage/chemrxiv/public-dashboard) has "Most read" and "Most cited" sections — but all-time, not date-filtered, and titles don't extract via text fetch (only author lists render).

  4. Per-paper Google snippet lookup for view counts: unreliable — new-format DOI pages don't surface consistently.

Bottom line: view/download ranking for the past month cannot be verified from any accessible source. The list is curated, not metrics-ranked.

Signals that can corroborate editorial picks

Free for non-commercial research by application (review targets ~30 business days). The highest-leverage upgrade for the four editorial tabs.

    Was the free alternative to Altmetric: DOI mentions across blogs, social media, Wikipedia and more. Retired by Crossref (public API reported gone from April 2026); only a historical archive remains. Not usable for new papers.

    Open scholarly graph with citation counts, successor to Microsoft Academic Graph. Month-old preprints have essentially no citations, and fresh PsyArXiv DOIs 404'd at scout time. Use it for a 3–6 month retrospective: how did each edition's picks age?

    Citation and “influential citation” counts covering papers and preprints. Same timing problem as OpenAlex; a second opinion on citations for the retrospective.

  • Scietycheck per paper

    eLife-built aggregator of community peer evaluations of preprints from dozens of review groups. Look up individual picks; an evaluation or curation statement is independent corroboration. PsyArXiv coverage not confirmed.

  • PREreviewcheck per paper

    Open, ORCID-signed preprint reviews with DOIs. Explicitly supports PsyArXiv, SocArXiv, OSF, medRxiv and bioRxiv. A published review of a pick is strong corroboration.
