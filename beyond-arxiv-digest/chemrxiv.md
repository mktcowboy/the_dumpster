# Chemistry — ChemRxiv Top 20, Sep 18 – Oct 18, 2026 (scout report, received Oct 18, 2026)

## Statistics hunt — what was actually found
1. ChemRxiv article pages DO display public metrics — every article page shows "N views / M downloads" (confirmed via Google-indexed snippets, e.g. "1,665 views / 581 downloads"). BUT: article pages return HTTP 403 to programmatic fetching (bot protection), and there is no sortable, date-filterable, or API-exposed ranking of these metrics anywhere.
2. The ChemRxiv dashboard (https://chemrxiv.org/engage/chemrxiv/public-dashboard) has "Most read" and "Most cited" sections — but all-time, not date-filtered, and titles don't extract via text fetch (only author lists render).
3. Altmetric API: 403 to the fetcher. Web search for a ChemRxiv metrics API / trending page / docs: nothing public.
4. Per-paper Google snippet lookup for view counts: unreliable — new-format DOI pages don't surface consistently.

Bottom line: view/download ranking for the past month cannot be verified from any accessible source. The list is curated, not metrics-ranked.

## Exact methodology
- Complete enumeration: queried the Crossref API for all works with prefix 10.26434 (ChemRxiv) published 2026-09-18 → 2026-10-18: 1,431 preprints. Every title scanned.
- "Top" = editorial judgment on novelty, potential impact, attention-worthiness, with deliberate mix across subfields (organic, inorganic, catalysis/energy, materials, physical/theoretical, bio/medicinal, environmental).
- Filters: first versions only (v1); excluded withdrawn papers, replies/comments, v2+ updates of older papers.
- Verification: 13 of 20 papers had title/authors/date/abstract confirmed via individual Crossref record fetches. The other 7 have titles confirmed via the Crossref enumeration; authors could not be verified (rate-limited) and dates approximated (~) from list position/ID sequencing — flagged inline. Nothing invented; every URL follows the https://chemrxiv.org/doi/full/<DOI> pattern confirmed in Crossref records.
