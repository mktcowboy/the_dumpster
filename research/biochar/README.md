# Biochar staging pack

Dumpster staging for carbon-based water filtration research. This folder is not the work repository, and it is not the canonical home for soil or carbon-dioxide-removal science.

The water-treatment report was already on this branch. The attached copy matches it byte for byte, so that file was left unchanged. The PPP notes and the shortlist CSV are the attached files, copied unchanged. The papers audit is the attached HTML with the repository-owner handle removed so the privacy check can pass.

## Contents

| Path | What it is |
| --- | --- |
| [biochar-activated-carbon-water-report.html](biochar-activated-carbon-water-report.html) | Self-contained evidence review of biochar and activated carbon for water treatment and contaminant removal. Dated in the report as checked October 22, 2026. |
| [water-infrastructure-ppp-notes.html](water-infrastructure-ppp-notes.html) | Notes on U.S. water-infrastructure public-private partnerships, cleanup, and restoration. RES means Resource Environmental Solutions. The notes link to the water-treatment report beside them. |
| [carbon-water-papers-audit.html](carbon-water-papers-audit.html) | Audit of a papers collection used for carbon-based water treatment, including the cite-first shortlist and the three known DOI errors. |
| [Water-purification/bibliography/](Water-purification/bibliography/) | Cite-first water and filtration bibliography. Separate from soil and carbon-dioxide-removal science. See that folder's README for tiers and the file list. |

## How to use this pack

- Read the water-treatment report for the narrative review and its 25 references.
- Cite from `Water-purification/bibliography/`. Prefer shortlist tiers A and B. Vendor material is a lower tier and is not in the shortlist.
- Read `Water-purification/bibliography/doi-corrections.md` before reusing DOIs from the work repository's top-20 list.
- Treat the PPP notes as infrastructure context. Company-sourced claims are flagged inside that file.
