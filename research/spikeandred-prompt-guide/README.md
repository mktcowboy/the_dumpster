# Spikeandred Prompt Field Guide

A self-contained HTML guide to the visual language of [@spikeandred](https://www.instagram.com/spikeandred/): 12 photographic prompts, a consistency system for scene-to-scene variation, and a campaign playbook from brief to test.

- `index.html` — the full report. Open in a browser; no server or installation needed.
- Interactive: category filters, copy buttons, prompt-pack download, and print/PDF styles.
- References link to the source account and related public pages. No source images are reproduced.
