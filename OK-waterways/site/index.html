Data sources

  • USGS National Hydrography Dataset (NHD), High Resolution — Oklahoma state extract (NHD_H_Oklahoma_State_GDB, staged by The National Map, published Dec 2023; the NHD is now a static, retired dataset). Flowlines, waterbodies, areas, lines and points; stream order from NHDFlowlineVAA.
  • USGS Watershed Boundary Dataset (WBD) — HUC2–HUC12 layers from the same staged product.
  • USGS NWIS site service — stream and lake monitoring locations in Oklahoma with daily or real-time data (fetched at build time).
  • US Census Bureau 2023 cartographic boundaries (1:500k) — state outline used to clip features, counties for county attribution.

Method notes

  • All NHD features are clipped to the Oklahoma state boundary; lengths and areas are computed in CONUS Albers (EPSG:5070) for the in-state portion.
  • The streams table groups named flowlines (Stream/River, Artificial Path, Canal/Ditch, Connector) by GNIS name/ID. Unnamed streams are on the map and in the totals but not in the table.
  • Lakes table: named NHD waterbodies grouped by GNIS name/ID (area summed over polygons, in-state portion only). County = county containing each polygon's interior point.
  • Watersheds: every WBD unit with any area in Oklahoma; area is the full unit area, with the share inside Oklahoma.
  • Vector tiles built with tippecanoe (max zoom 12; geometry simplified at lower zooms; maps overzoom beyond).

Source code and build script live in the OK-waterways folder of this repository.
