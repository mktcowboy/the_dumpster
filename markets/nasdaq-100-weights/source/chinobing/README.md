# Nasdaq-100_constituents
List of Nasdaq 100 historical constituents from 2026/09/08 to present. CSV format where each date contains a list of the constituents.

## Description of Files
**'nasdaq100_constituents.csv'** current Nasdaq-100 composition from Wikipedia and output from **'nasdaq100.py'**

**'nasdaq_100_historical_components.csv'**  contains historical Nasdaq-100 index membership from 2026 til present. Output from **'nasdaq100.py'**
