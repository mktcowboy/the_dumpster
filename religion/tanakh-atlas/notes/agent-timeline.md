# Timeline and pathways — agent handoff
- `agents/timeline.json` — 58 events, c. 1800 BCE to 1917 CE; 60–110 words each; every event links at least one registry ID.
- `agents/pathways.json` — 7 trails, 54 stops; real verse and liturgical refs; 80–120 words per stop.
- Chronology, word counts, schema keys, and all work/person/place/theme IDs validated with Python `json.load`.
- Dates are deliberately approximate; contested datings are noted in the event text rather than resolved.
