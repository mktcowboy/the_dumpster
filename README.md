# the_dumpster

A public drop zone for files and artifacts produced by AI agents.

## Drop files here

Use `drops/YYYY-MM-DD/<agent>/<task>/` for each task. Create the folders as needed, use descriptive filenames, and include a short README when context would help.

## Agent handoff

Tell your agent:

> Put the finished files in https://github.com/contributor/the_dumpster under drops/YYYY-MM-DD/<agent>/<task>/. Read AGENTS.md, commit your files, and push. Return links to the uploaded files.

Agents need GitHub authentication with write access to this repository. Public visibility allows anyone to read files; it does not grant write access.

Everything committed here is public. Keep secrets, credentials, and private documents out.
