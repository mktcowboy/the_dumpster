# Data Center Deals

Searchable database of publicly announced data center deals (new builds, expansions, leases, acquisitions, financings, project-tied power), split by half-year to keep each file self-contained.

- `data-center-deals-2025-h1.html` — 2025 H1 deals (67)
- `data-center-deals-2025-h2.html` — 2025 H2 deals (134)
- `data-center-deals-2026-h1.html` — 2026 H1 deals (113)
- `data-center-deals-2026-h2.html` — 2026 H2 deals, through Oct 12, 2026 (65)
- `data-center-deals-all.html` — all four combined into one fully linked report: every number, date, deal type, place and company is clickable (numbers open a panel listing the exact deals behind them), plus a by-state map, country breakdown, 288 company profiles with all their deals, and a numbered reference list

379 deals total. Each file is self-contained (no external requests): text search, filters by deal type and quarter, sortable table. Every deal links to its source announcement. MW and dollar figures appear only where a source stated them.
