# Diesel Wholesale Market Analysis

Single self-contained HTML file on buying diesel wholesale, red (dyed) vs clear diesel, futures, and hedging, tailored to a mixed on-road + off-road operation.

- Market snapshot as of Oct 26, 2026: US retail diesel $6.28/gal (week of Oct 19, 2026), NY Harbor wholesale $5.03, ULSD futures $4.77, distillate stocks 105.1M bbl (~12% under the 5-year average).
- Price stack: crude -> crack spread -> NYMEX ULSD -> Oklahoma / Group 3 basis -> freight -> jobber margin -> taxes.
- Wholesale buying: tank wagon, transport load (7,500+ gal), wet-hose, and "rack plus" contracts with negotiation levers.
- Red vs clear: same ASTM D975 ULSD, ~43-44c/gal Oklahoma tax saving on legitimate off-road use, federal penalty greater of $1,000 or $10/gal, dye persistence, and the Oct 1-Dec 31, 2026 temporary relief warning (tax deferred, not forgiven; state rules still apply).
- Mixed-operation plan: separate tanks, labels, nozzles, eligible-unit list, and per-stream logging.
- Hedging: physical fixed-price contracts, NYMEX ULSD futures (42,000 gal/contract), swaps, caps/collars, fuel surcharge pass-through, basis risk, and a laddered hedge (40-55% / 25-35% / 10-20% / 5-10%, never 100%).
- Includes working calculators for rack-plus delivered price and mixed-stream exposure. Calculator defaults are illustrative only (4,000 off-road + 6,000 on-road gal/month, 43.5c/gal tax gap) - edit to actual volumes.

Not tax or trading advice. Sources cited in the file footer (EIA, CME, IRS Pub. 510 / Sec. 6715).
